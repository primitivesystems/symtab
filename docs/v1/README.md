# Symtab v1 guide

Symtab is a desktop workspace for plain Markdown notes. Your notes stay in folders you choose, while Symtab adds journaling, search, links, backlinks, tags, archive, trash, and a visual graph.

## v1 scope

Symtab v1 focuses on local Markdown workflows: file management, journaling, archive and trash recovery, graph navigation, vault management, and onboarding. AI mode, plugins, version control, and publishing are not shipped as v1 features.
