# Keyboard shortcuts

These shortcuts are implemented in Symtab v1. On Windows and Linux, use `Ctrl` where macOS uses `Command`.

| Action | Shortcut |
| --- | --- |
| Open command palette | `Command+Shift+P` |
| Search notes | `Command+Shift+F` |
| Open or create a vault | `Command+O` |
| Open Settings | `Command+,` |
| Open a new window | `Command+Shift+N` |
| Switch light/dark theme when focus is outside an editor or form | `D` |
| Close command palette or an open journal overlay | `Escape` |
| Fit focused graph to view | `Home` |

Standard platform editing shortcuts such as undo, redo, copy, paste, select all, and find are supplied by Electron or the editor where applicable.
